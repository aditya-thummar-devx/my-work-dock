Free · macOS 14 Sonoma or later · Apple Silicon (M1 and newer)

What is inside

Clipboard

Searchable text history with tags and pins. Password managers are never recorded.

Notes

TODOs, plus saved Commands, Prompts and Links. Double-click any of them to copy.

claudex

Usage gauges and account switching for the optional claudex CLI, plus tokens and cost from Claude Code’s own transcripts (no CLI needed).

Emulator

Start and stop iOS simulators and Android emulators, pair devices over Wi-Fi, run adb reverse tunnels.

Global hotkeys

Jump straight to a tab from any app with ⌘ ⇧ plus a letter.

Updates itself

Checks hourly and installs quietly when you are not using it.

macOS will block it the first time.

MyWorkDock is not notarized by Apple, so Gatekeeper shows a warning on first launch. It takes about a minute to get past: step-by-step guide.

Get started

  1. Install it: download the DMG and drag the app to Applications.
  2. Get past the privacy blocker: once, on first launch.
  3. Learn the basics: hover, click, hotkeys.
  4. Tour every feature.
