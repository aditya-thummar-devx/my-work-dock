Updates and changelog

MyWorkDock updates itself. You do not need to download anything again.

How it works

  1. Once an hour the app checks for a newer version.
  2. If there is one, it downloads it quietly in the background.
  3. When nothing would be interrupted, it installs the update and restarts itself. That means the panel is closed, no confirmation is showing, and no simulator is booting or claudex change is running.

Updates are delivered with Sparkle, a widely used macOS updater. Every update is signed, and the app checks the signature before installing it. The update feed is a file attached to the latest GitHub release.

Check now

Any of these runs a check straight away and shows the result, including the release notes:

  • Settings › Version › Check for updates
  • The menu-bar icon › Check for Updates…
  • Right-click the notch bar › Check for Updates…

Settings › Version also shows your current version and when it last updated.

Changelog

Release notes for every version are on the Releases page. Each release lists the changes since the previous one.

If an update does not arrive

  • Make sure the app is in /Applications and that you are online.
  • Leave the panel closed for a few minutes so the app counts as idle.
  • Run Check for updates from Settings › Version to see any error.
  • As a last resort, download the latest DMG and replace the app. Your data is kept: it lives outside the app (details).
