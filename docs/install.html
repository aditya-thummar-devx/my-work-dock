Install

Download, drag, open. The only fiddly part is the one-time macOS warning, covered on the next page.

Requirements

  • macOS 14 Sonoma or later.
  • Apple Silicon (M1, M2, M3, M4 and newer). Intel Macs are not supported.
  • Optional, only for the tabs that use them: Xcode (iOS simulators), the Android SDK (adb and emulator), and the claudex CLI. Everything else works without them.

Steps

  1. Open the latest release and download the file ending in .dmg (under Assets).
  2. Open the DMG and drag MyWorkDock onto the Applications shortcut in the same window.
  3. Eject the DMG, then open MyWorkDock from Applications.
  4. macOS will refuse to open it. That is expected. Follow Get past the privacy blocker, then open the app again.
  5. There is no Dock icon. Look for the small icon in the menu bar and the dark bar at the top of your screen. Hover it to see the peek, click it to open the panel.
Keep it in Applications.

Run it from /Applications, not from the DMG or Downloads. Automatic updates replace the app in place and need a normal install location.

Start at login (optional)

MyWorkDock does not start at login by default. To turn it on, right-click the notch bar and choose Open at login. A tick shows when it is on. You can also manage it in System Settings › General › Login Items.

Build from source

If you would rather build it yourself you need Xcode and XcodeGen:

git clone https://github.com/aditya-thummar-devx/my-work-dock.git
cd my-work-dock
xcodegen generate
open MyWorkDock.xcodeproj

A build you make yourself is signed on your own Mac and does not hit the Gatekeeper warning. It also does not receive automatic updates in debug configuration.
